# Consignes pour les assistants de code

## Commits et pull requests

- Ne jamais mentionner Claude, Anthropic ou un assistant IA comme auteur, co-auteur ou contributeur.
- Aucune ligne `Co-Authored-By`, `Claude-Session` ni « Generated with Claude Code » dans les messages de
  commit, les descriptions de pull request ou les commentaires.
- Les commits sont signés au nom du propriétaire du dépôt (`nganjie <nganjienzatsi@gmail.com>`).
