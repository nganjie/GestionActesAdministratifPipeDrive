Réinitialiser la démonstration

Repartir d'un jeu de données propre, dans l'application et dans Pipedrive.

Le mode démonstration est désactivé sur ce serveur. Pour l'activer, ajoutez MODE_DEMO=true dans le fichier .env de l'API puis redémarrez-la. Ne l'activez jamais en production.

Ce qui va se passer

  • Tous les dossiers de ce serveur sont effacés : demandeurs, pièces, décisions, historique, synchronisations.
    • {% if etat.pipedrive %}
  • Dans Pipedrive, les deals dont le titre commence par ACT- du pipeline « {{ etat.pipeline }} » et leurs activités sont supprimés. Rien d'autre n'est touché ; les contacts sont conservés et réutilisés.
    • {% else %}
  • Pipedrive n'est pas configuré sur ce serveur : seule la base locale est réinitialisée.
    • {% endif %}
  • Les 10 dossiers de démonstration sont rechargés{% if etat.pipedrive %}, puis envoyés à Pipedrive par le worker{% endif %}.
  • Les comptes, la configuration des démarches et les journaux techniques sont conservés.
{% if etat.pipedrive %}

Si un autre serveur est relié au même compte Pipedrive, arrêtez son worker ou videz son PIPEDRIVE_API_TOKEN : sinon il recréera ses propres deals.
